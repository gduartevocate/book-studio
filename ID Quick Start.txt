Book Studio ID v2026.09.21.10

1. Preferred: install with git so updates are one click. In PowerShell: git clone https://github.com/gduartevocate/book-studio
   If you received this as a ZIP instead, unzip it; ZIP installs are updated by replacing the folder.
2. Use a local writable folder outside OneDrive or other sync folders for the pilot. Double-click Start Book Studio.cmd.
3. Your browser should open to Book Studio automatically.
4. Keep using the browser while the server runs in the background.
5. Double-click Stop Book Studio.cmd when finished.

Version check and updates:
- The Book Studio header shows the installed Book Studio ID version and an Update available badge when a newer release exists.
- Settings > Updates > Get latest updates downloads the release and restarts Book Studio. Books, uploads, and settings stay in place.
- When troubleshooting, report this exact version: v2026.09.21.10.

Codex assistant and AI generation:
- AI drafting and real chapter-image generation are enabled by default. All chapter images must pass generation and Word/HTML checks; disabled or partial image runs remain incomplete.
- Those AI generation options require Codex CLI to be installed and signed in on that Windows user.
- Book Chat and AI-assisted package edits also require Codex CLI.
- Cached sign-in does not prove a working connection. Click Test connection before AI generation or chat.
- If a refresh-token error appears, use the recovery instructions for the displayed executable/profile; do not copy another user's credentials.
- If Codex is installed but Book Studio cannot find it, use the Codex Assistant panel or copy codex-path.example.txt to codex-path.txt and replace the example with the full path to codex.exe.
- IDs can uncheck Codex AI drafting and Codex image banners to run the local scaffold/export path only, but that is not the production-quality SME draft workflow.

New-book workflow:
- Upload readable DOCX/TXT/Markdown/HTML/JSON documents; convert PDFs/scans first.
- Choose the authoritative blueprint explicitly. Duplicate filenames are preserved.
- Uploaded documents only is the default: no external reading discovery. Internet access is still needed for Codex.
- Review intake coverage, then the format preview. Apply a supported layout option to change it.
- Additional notes do not automatically change typography; resolve them before approval.
- Approve the current preview, generate, and review the quality results and actual Word/PDF pages.
- A completed run is not publication approval. Academic and permissions review still apply.
- Follow docs/book-studio-pilot-checklist.md before using this on another computer.

Local data:
- Book Studio creates .bookstudio next to these files.
- Uploads, generated books, logs, and job history stay in that .bookstudio folder.
- Do not delete .bookstudio unless you intentionally want to remove local work.

Cloudflare SME review:
- Cloudflare publishing requires a real .env file beside Start Book Studio.cmd.
- Use .env.example as the template.
- Never send real API tokens by email or chat.
